# Adapter artifacts

- `index.json` binds the adapter contract, fixture set, expected outcomes, and SHA-256 receipts.
- `fixtures/` covers valid, invalid, unknown, conflict, satire, cross-mode, missing-provenance, and drift cases.
- `reports/conformance.json` is the deterministic 3-adapter by 8-fixture conformance matrix.

Adapters translate transport. They do not redefine truth.

See `docs/ADAPTERS.md`.
