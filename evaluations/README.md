# Consumer evaluation artifacts

- `index.json` binds the exact fixture set and pinned parent evidence identity.
- `cases/` contains seven deterministic synthetic metric fixtures.
- `runs/` contains explicitly non-executed synthetic conformance manifests.
- `reports/` contains deterministic derived evaluation reports.
- `comparisons/` contains deterministic, identity-gated report comparisons.

See `docs/CONSUMER-EVALUATIONS.md`.
