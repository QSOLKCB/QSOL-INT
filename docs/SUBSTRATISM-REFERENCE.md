Repository: `QSOLKCB/substratism`

Status in QSOL-INT: **non-canonical methodology reference; not a parent protocol.**

## Why it belongs here

The Substratism VIZ project already enforces a distinction QSOL-INT needs: published research fixtures remain separate from project-authored explanatory receivers. Its deterministic sonification/visual reconstruction is explicitly described as explanatory rather than an intrinsic signal or evidence for the underlying moral/ontological claim.

INT generalizes that discipline:

- parent contract / source evidence -> **source fixture**;
- INT visualization, mapping, compatibility report, reconstruction, or score -> **authored receiver**;
- authored receiver -> derived explanation only;
- authored receiver must never redefine or strengthen source semantics.

## Adopted invariant

`AUTHORED_RECEIVER != SOURCE_EVIDENCE`

This complements INT's primary invariant:

`INTEGRATION_MUST_NOT_INCREASE_SEMANTIC_AUTHORITY`

## What INT does not inherit

INT does not import the Substratism Scale, moral claims, coefficients, visual design, or sonification mappings as integration semantics. The reference is methodological only.
